# 框架与算法说明

本文件说明 `coupledsim` 的整体框架、坐标约定、流体算法，以及为后续软体 / 刚体
耦合预留的接口。对应选题方案见 [`../lab4_project_proposal.md`](../lab4_project_proposal.md)。

## 1. 设计目标

- **分层、可独立测试**：流体 / 软体 / 刚体各为一个模块，通过统一的“固体边界”
  接口与流体网格交互；每个模块都能在 headless 下单独验证。
- **统一坐标与时间步**：所有模块共享 `FluidConfig` 里的网格、`dx`、`dt`、子步约定。
- **先把核心闭环做稳**：第一阶段交付一个稳定的二维 FLIP/PIC/APIC 水箱，
  并把“固体作为流体边界”的接口实现出来，作为双向耦合的地基。

## 2. 目录结构

```
src/coupledsim/

  fluid/flip_solver.py # 流体求解器（核心）

  softbody/            # 软体（FEM/XPBD），占位

```

## 3. 坐标与网格约定（交错 MAC 网格）

世界坐标 `[0, Lx] x [0, Ly]`，单元边长 `dx = Lx / nx`，`Ly = ny * dx`。

| 量 | 存储位置 | 字段形状 | 世界坐标 |
|----|----------|----------|----------|
| `u`（x 速度） | 竖直面（单元左右边） | `(nx+1, ny)` | `(i·dx, (j+0.5)·dx)` |
| `v`（y 速度） | 水平面（单元上下边） | `(nx, ny+1)` | `((i+0.5)·dx, j·dx)` |
| 压力 `p` / 单元类型 | 单元中心 | `(nx, ny)` | `((i+0.5)·dx, (j+0.5)·dx)` |
| 固体距离 `solid_phi` | 单元中心 | `(nx, ny)` | 同上，`<0` 表示固体内部 |

交错网格能让压力梯度与散度在同一套面上自然离散，避免棋盘格压力震荡。

## 4. 流体算法：FLIP / PIC / APIC

粒子携带流体（位置 + 速度，APIC 另带仿射矩阵 `C`），网格用于求解不可压缩压力。
每个子步：

1. **P2G**（`p2g`）：用二次 B 样条权重把粒子速度散布到 `u`/`v` 面。
   - APIC 额外加入仿射项 `C·(x_node − x_p)`。
   - 二次 B 样条的惯性张量为常数 `D = dx²/4`，使 APIC 的 `C` 计算简洁且精确。
2. **归一化**（`normalize_grid`）：网格速度 = 加权平均；保存投影前速度 `u_old/v_old`
   供 FLIP 计算增量。
3. **单元分类**（`classify_cells`）：`solid_phi<0` → SOLID；含粒子 → FLUID；其余 AIR。
4. **体力**（`add_gravity`）：重力加到流体面速度。
5. **固体边界**（`apply_solid_boundaries`）：固体面法向速度置为固体速度（静态即 0）。
5b. **粘性扩散**（`apply_viscosity`，可选）：对网格速度做显式 Jacobi 扩散
   `u += ν·τ·∇²u`，按稳定性 `ν·τ/dx² ≤ 0.25` 自动细分内部子步；
   固体面提供无滑移边界。`viscosity=0` 时跳过。
6. **压力投影**（`solve_pressure`）：解压力 Poisson 使速度近似无散。
   - 默认 **Jacobi 预条件共轭梯度 (PCG)**，收敛快、残差可降到 ~1e-5。
   - 备选红黑 Gauss–Seidel（`use_cg=False`）。
   - 自由表面用 Dirichlet `p=0`（空气）、固体用 Neumann（无通量）边界。
7. **速度外插**（`extrapolate`）：把流体速度推到邻近空气面，减少自由表面伪影。
8. **G2P**（`g2p`）：
   - PIC：`v_p = interp(v_grid)`（最稳、耗散大）
   - FLIP：`v_p += interp(v_grid − v_old)`，再与 PIC 按 `flip_ratio` 混合
   - APIC：`v_p = interp(v_grid)` 且重建仿射矩阵 `C`（低耗散、稳定）
9. **平流 + 投影**（`advect_particles`）：RK2 中点法推进粒子；越界裁剪；
   落入固体则沿 `solid_phi` 梯度推出并去除指向固体的法向速度。

### 压力方程离散（与代码一致）

定义 `scale = dt / (ρ·dx²)`，散度 `div = (u_{i+1,j} − u_{i,j} + v_{i,j+1} − v_{i,j}) / dx`。
线性系统 `A p = b`：

- `(A p)_{i,j} = scale · ( n_nonsolid · p_{i,j} − Σ_{流体邻居} p_nb )`
- `b_{i,j} = −div_{i,j}`

`A` 对称正定，故可用 PCG。速度修正：`u_{i,j} −= (dt/ρ)·(p_{i,j} − p_{i−1,j})/dx`。

### 数值稳定性手段

子步推进、自适应子步（按最大速度的 CFL）、网格/粒子速度限幅、可选整体阻尼
`vel_damping`、粒子出界裁剪与固体投影。这些也是后续耦合不炸的基础。

## 5. 耦合接口（关键）

流体求解器**只**依赖三个网格量来表示一切固体：

```
solid_phi[i,j]   单元中心到最近固体表面的有符号距离（<0 在固体内）
u_solid[i,j]     竖直面上的固体法向速度
v_solid[i,j]     水平面上的固体法向速度
```

- **流体 → 固体**：固体可在自己表面采样流体速度场（`sample_velocity`）/ 压力，
  估计拖拽力、浮力、压力差。
- **固体 → 流体**：固体把自身栅格化为 `solid_phi` 与表面速度写入上述字段，
  流体在分类、边界、投影中即把它当作（可动）墙处理。

当前 `coupling/boundary.py` 实现的是**静态解析障碍**（盒 / 圆 / 水箱壁）。
接入软体 / 刚体时，只需让它们每步更新 `solid_phi` 与表面速度即可，**无需改流体内核**。

## 6. 后续阶段对接计划

- **软体（FEM/XPBD）**：二维三角网格角色；表面点采样流体力（单向耦合），
  再把软体占据写回 `solid_phi`（双向耦合）。
- **刚体 / 机关**：可拖动挡板、浮块、按钮，作为可动固体边界，累计流体力驱动。
- **稳定性**：从低分辨率、单向耦合开始，逐步加力限幅 / 子步 / 阻尼到双向耦合。

- PIC/FLIP/APIC 三模式多帧无 NaN、粒子守界、粒子数守恒；
- 溃坝水柱坍塌、向右铺开（合乎重力直觉）；
- 障碍盒不被粒子穿入。
