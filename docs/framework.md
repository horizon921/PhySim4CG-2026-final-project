# 框架与算法说明（三维）

本文件说明 `coupledsim` 的整体框架、坐标约定、流体算法，以及为后续软体 / 刚体
耦合预留的接口。对应选题方案见 [`../lab4_project_proposal.md`](../lab4_project_proposal.md)。

## 1. 设计目标

- **分层、可独立测试**：流体 / 软体 / 刚体各为一个模块，通过统一的“固体边界”
  接口与流体网格交互；每个模块都能在 headless 下单独验证。
- **统一坐标与时间步**：所有模块共享 `FluidConfig` 里的网格、`dx`、`dt`、子步约定。
- **先把核心闭环做稳**：第一阶段交付一个稳定的三维 FLIP/PIC/APIC 水箱，
  并把“固体作为流体边界”的接口实现出来，作为双向耦合的地基。

## 3. 坐标与网格约定（三维交错 MAC 网格）

世界坐标 `[0,Lx]×[0,Ly]×[0,Lz]`，立方体单元边长 `dx = Lx/nx`，`Ly=ny·dx`，`Lz=nz·dx`。

| 量 | 存储位置 | 字段形状 | 世界坐标 |
|----|----------|----------|----------|
| `u`（x 速度） | x 面 | `(nx+1, ny, nz)` | `(i·dx, (j+½)·dx, (k+½)·dx)` |
| `v`（y 速度） | y 面 | `(nx, ny+1, nz)` | `((i+½)·dx, j·dx, (k+½)·dx)` |
| `w`（z 速度） | z 面 | `(nx, ny, nz+1)` | `((i+½)·dx, (j+½)·dx, k·dx)` |
| 压力 `p` / 单元类型 / `solid_phi` | 单元中心 | `(nx, ny, nz)` | `((i+½)·dx, (j+½)·dx, (k+½)·dx)` |

交错网格让压力梯度与散度在同一套面上自然离散，避免棋盘格压力震荡。

## 4. 流体算法：FLIP / PIC / APIC

粒子携带流体（位置 + 速度，APIC 另带 3×3 仿射矩阵 `C`），网格用于求解不可压缩压力。
每个子步：

1. **P2G**（`p2g`）：用三维二次 B 样条权重（3×3×3 模板）把粒子速度散布到
   `u`/`v`/`w` 面。APIC 额外加入仿射项 `C·(x_node − x_p)`（按分量分别重建）。
   二次 B 样条惯性张量为常数 `D = dx²/4`，使 APIC 的 `C` 计算简洁精确。
2. **归一化**（`normalize_grid`）：网格速度 = 加权平均；保存投影前速度供 FLIP 用。
3. **单元分类**（`classify_cells`）：`solid_phi<0` → SOLID；含粒子 → FLUID；其余 AIR。
4. **体力**（`add_gravity`）：重力加到流体面速度。
5. **固体边界**（`apply_solid_boundaries`）：固体面法向速度置为固体速度（静态即 0）。
5b. **粘性扩散**（`apply_viscosity`，可选）：对网格速度做显式 Jacobi 扩散
   `u += ν·τ·∇²u`（六邻域），按稳定性 `ν·τ/dx² ≤ 1/6` 自动细分；固体面无滑移。
6. **压力投影**（`solve_pressure`）：解压力 Poisson 使速度近似无散。
   默认 **Jacobi 预条件共轭梯度 (PCG)**（自由表面 Dirichlet `p=0`，固体 Neumann）。
7. **速度外插**（`extrapolate`）：把流体速度外插到邻近空气面，减少自由表面伪影。
8. **G2P**（`g2p`）：PIC（覆盖）/ FLIP（加增量后与 PIC 混合）/ APIC（覆盖并重建 `C`）。
9. **平流**（`advect_particles`）：RK2 推进；越界裁剪；落入固体则沿 `solid_phi`
   梯度推出并去除指向固体的法向速度。

### 压力方程离散（与代码一致，三维 6 邻域）

`scale = dt/(ρ·dx²)`，`div = (u_{i+1}−u_i + v_{j+1}−v_j + w_{k+1}−w_k)/dx`。
线性系统 `A p = b`，`A` 对称正定：

- `(A p) = scale·( n_nonsolid·p − Σ_{流体邻居} p_nb )`（6 个邻居）
- `b = −div`

速度修正：`u_{i,j,k} −= (dt/ρ)·(p_{i,j,k} − p_{i−1,j,k})/dx`（v/w 类推）。

### 稳定性手段

子步推进、自适应子步（按最大速度 CFL）、网格/粒子速度限幅、可选整体阻尼
`vel_damping`、粒子出界裁剪与固体投影。这些也是后续耦合不炸的基础。

## 5. 耦合接口（关键）

流体求解器**只**依赖这些网格量来表示一切固体：

```
solid_phi[i,j,k]                单元中心到固体表面的有符号距离（<0 在固体内）
u_solid / v_solid / w_solid     交错面上的固体法向速度
```

- **流体 → 固体**：固体可在表面用 `solver.sample_velocity(x)` 采流体速度 / 压力，
  估计拖拽力、浮力、压力差。
- **固体 → 流体**：固体把自身栅格化为 `solid_phi` 与表面速度写入上述字段，
  流体在分类、边界、投影中即把它当作（可动）墙处理。

`coupling/boundary.py` 是该接口的**静态解析实现**（盒 / 球 / 水箱壁）。
`softbody/xpbd.py` 进一步把软体节点栅格化为运动球 SDF，并向交错面写入软体速度，
从而形成基础双向耦合，**无需改流体内核**。

## 6. 软体模块（XPBD）

当前软体使用三维 XPBD 距离约束晶格：

1. 节点携带位置、速度、质量，约束保存静止长度。
2. 每步先用重力、阻尼、流体拖拽预测位置。
3. 多轮 XPBD 距离约束投影恢复体积感和弹性。
4. 对水箱边界与静态障碍做位置投影。
5. 将节点视为一组运动小球，和静态边界取 SDF 并集写回 `solid_phi`；
   同时把节点速度散布到 `u_solid/v_solid/w_solid`。

该实现优先保证交互稳定和展示闭环。它不是高精度连续介质 FEM，但可以表现果冻体
被水流推动、变形、挡水、改变流路的核心现象，并为后续替换四面体 FEM 留出同样的
耦合接口。

## 7. 渲染与性能

- **离屏渲染** `render/offscreen.py`：正交投影 + 画家算法 + 深度明暗，
  把三维粒子云画成 PNG（含水箱线框参考），用于报告出图与 headless 检查。
- **交互查看器** `render/viewer.py`：`ti.GUI`（CPU 软件光栅）+ `set_image` 显示
  上述投影，鼠标左键拖动旋转相机。**不依赖 GGUI/vulkan**。
- **后端**：默认 `ti.cpu`。GPU（metal/vulkan）后端在本机会卡住——压力 PCG 的
  逐迭代标量读回造成大量主机同步停顿。三维开销 ∝ `res³`，分辨率是主要速度旋钮。

## 8. 后续阶段对接计划

- **软体升级**：将当前 XPBD 晶格替换 / 扩展为三维四面体 FEM，使用表面三角形
  做更准确的 SDF 与压力力估计。
- **刚体 / 机关**：可拖动挡板、浮块、按钮，作为可动固体边界，累计流体力驱动。
- **稳定性**：从低分辨率、单向耦合开始，逐步加力限幅 / 子步 / 阻尼到双向耦合。

## 9. 验证

`tests/test_fluid_headless.py`（均为三维）：压力投影散度下降到 ~1e-5；
PIC/FLIP/APIC 多帧无 NaN、粒子守界、粒子数守恒；溃坝质心下降并水平铺开；
障碍盒/球不被粒子穿入；粘度单调降低动能；离屏 / 交互渲染路径可用。

`tests/test_softbody_headless.py`：XPBD 软体单独稳定性、动态 SDF 栅格化、
`softbody` 场景中软体-流体耦合 headless 推进。
