# Lab4 小游戏目标与关卡说明

本文档说明软体-流体耦合小游戏的玩法目标、胜负条件和三关设计。运行方式见根目录下的 `game_run_guide.md`。

## 1. 游戏核心目标

玩家不是直接控制软体，而是控制水流喷口。水流推动 XPBD 软体果冻运动，果冻又会作为动态边界反过来影响流体。

核心玩法可以概括为：

```text
用有限水量控制喷流，把橙色软体果冻推入绿色目标区，并避开红色危险区。
```

这对应本项目的物理仿真重点：

```text
流体 -> 软体：水流速度场对软体施加拖拽/推动力
软体 -> 流体：软体被栅格化成动态固体边界，阻挡和改变水流
关卡逻辑：checkpoint、危险区、水量预算、脉冲冷却、胜负判定
```

## 2. 画面元素

```text
蓝色粒子       流体
橙色点/线框    XPBD 软体果冻
绿色框         checkpoint / 目标区
红色框         danger / drain / 危险区
灰色线框       仿真容器
灰色体素       固体障碍物
```

UI 元素：

```text
WATER          剩余水量预算
GOAL           当前目标区名称和完成进度
MATCH          软体采样点与当前目标区的匹配比例
JET ON/OFF     玩家喷口是否开启
黄色箭头       当前喷口方向
PLAYING        正在游戏
WON            已通关
LOST           已失败
```

## 3. 基本胜负条件

胜利条件：

```text
按顺序完成所有绿色 checkpoint。
软体中心进入当前 checkpoint，或者软体有足够一部分采样点匹配目标区后，
需要停留若干帧，GOAL 进度到 100% 才算完成。
```

失败条件：

```text
软体长时间停留在红色危险区。
软体跑出仿真容器。
超过关卡时间限制。
水量耗尽且没有可用流体继续推动软体。
```

得分来源：

```text
完成 checkpoint 获得基础分。
越快完成，剩余时间奖励越高。
剩余水量越多，额外奖励越高。
碰到危险区时会逐帧扣分。
```

## 4. 操作目标

常用操作：

```text
W / S      按住调整喷口向上 / 向下
A / D      按住调整喷口深度方向
I / K      兼容键：喷口向上 / 向下
J / L      兼容键：喷口深度方向
Q / E      减小 / 增大喷口速度
O          开关喷口
U          对软体附近触发一次脉冲推动
Space      暂停 / 开始
R          重置关卡
鼠标拖动    旋转视角
```

游玩思路：

```text
1. 先观察绿色目标框、红色危险框和黄色喷口箭头的位置。
2. 用 W/S/A/D 把喷流方向对准软体侧面。
3. 用水流逐步推软体，不要一味加速。
4. 软体快进入目标框时，可以关小喷口或关闭喷口，让它稳定停留。
5. 卡住时使用 U 脉冲，但脉冲会消耗水量并有冷却。
```

## 5. 关卡一：soft_plug

主题：

```text
入门关。学习如何用水流推动软体，并让软体稳定停在目标区。
```

目标顺序：

```text
1. align
2. seal
```

玩法说明：

```text
软体一开始在水流前方。
软体一开始就在 align 目标区附近，玩家先观察 GOAL 进度如何增长。
完成 align 后，再用水流把软体推向右侧 seal 目标区，模拟“用软体塞住出口/封堵通道”。
作为教学关，`soft_plug` 会对喷口方向做轻微辅助，让水流大致朝当前目标推进；玩家主要负责微调方向、控制喷水开关和观察 checkpoint 进度。
```

危险点：

```text
底部红色 drain 是危险区。
软体掉得太低并长时间停留在 drain 内会失败。
```

推荐策略：

```text
先等待 align 到 100%，理解 checkpoint 停留判定。
之后用默认喷流把软体往右推。
进入 seal 附近后不要继续猛推，必要时按 O 关掉喷口。
```

展示重点：

```text
软体被水推着移动。
软体进入目标区后触发 checkpoint 进度。
软体靠近危险区时，游戏事件和失败条件会响应。
```

## 6. 关卡二：soft_slalom

主题：

```text
绕障关。学习在障碍物之间引导软体转向。
```

目标顺序：

```text
1. left gate
2. right gate
3. finish
```

玩法说明：

```text
这一关有多个障碍物和两个方向不同的水流。
玩家需要让软体依次穿过左侧目标、右侧目标，最后到达 finish。
重点不是单纯往右推，而是通过喷口方向和水流速度控制软体绕开障碍。
```

危险点：

```text
中下方 side drain 是危险区。
软体被冲到过低位置时容易进入危险区。
```

推荐策略：

```text
先用主水流把软体推出起点。
接近障碍时，用 A/D 调整深度方向，让软体从侧面绕过。
必要时短暂提高喷口速度，但不要长期高速冲击。
```

展示重点：

```text
checkpoint 顺序约束。
障碍物改变流体路径。
玩家需要同时控制方向、速度和水量。
```

## 7. 关卡三：soft_rescue

主题：

```text
救援关。软体更重，水量更紧，需要先托举再推送。
```

目标顺序：

```text
1. lift
2. top seal
```

玩法说明：

```text
软体初始位置较低，而且质量更大。
玩家需要先用向上的水流把软体托到 lift 区域。
完成 lift 后，再把软体推到更高的 top seal 区域。
这一关强调水量管理和垂直方向控制。
```

危险点：

```text
bottom drain 位于底部，软体下沉太久会失败。
overflow 位于高处边界附近，软体被冲得过高也会失败。
```

推荐策略：

```text
先保持喷口有向上的分量，把软体从底部托起。
软体上升后降低速度，避免直接冲进 overflow。
U 脉冲适合用来脱困，但本关脉冲成本更高，要节约使用。
```

展示重点：

```text
更重软体带来的惯性和控制难度。
水量预算影响策略。
上下两个危险区让玩家不能只追求大速度。
```

## 8. 推荐演示说法

可以按下面这段话介绍项目：

```text
我们的小游戏不是直接拖动物体，而是通过流体来间接控制软体。
玩家调节喷口方向和强度，水流推动 XPBD 果冻通过目标区；
果冻同时会被栅格化为动态边界，反过来影响流体运动。
三个关卡分别展示基础封堵、绕障移动和重物托举，
把软体-流体双向耦合包装成了一个有目标、有资源限制、有失败条件的小游戏。
```
